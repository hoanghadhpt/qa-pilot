## Summary

Triển khai mô hình đóng gói 3 tầng (3-Tier Hybrid Packaging) cho `qa-pilot`:
1. **Tầng Skill (`.agents/skills/qa-pilot/`)**: Đóng gói mindset Senior QA, SFDIPOT, thư mục dữ liệu cục bộ (`data/`) chứa cẩm nang SFDIPOT, từ điển payload biên (`naughty-strings.json`), checklist nghiệm thu và script tìm kiếm zero-dependency (`search-heuristics.js`).
2. **Tầng Công cụ (`packages/mcp-server/`)**: Giữ nguyên làm MCP Server thực thi qua stdio (CDP, Playwright, Triple-Oracle, Suite Manager).
3. **Tầng Phân phối (`packages/cli/`)**: Cung cấp lệnh `npx qa-pilot init` cài đặt đồng bộ Skill, tích hợp an toàn `.mcp.json` và khởi tạo khung kiểm thử Playwright tiêu chuẩn.

---

## Technical Context

**Language/Version**: TypeScript 5.6+, Node.js >= 18.3.0 (sử dụng `util.parseArgs`, `node:fs/promises`, `node:path`)  
**Primary Dependencies**:
- Skill & CLI: **Zero external dependencies** (sử dụng 100% Node.js standard library để tối ưu tốc độ download qua `npx`)
- MCP Server: `@modelcontextprotocol/sdk`, `@playwright/test`, `@midscene/web`  
**Storage**: File-system based (JSON / Markdown / YAML), tuân thủ nghiêm ngặt Zero-Database  
**Testing**: Tự động hóa kiểm thử tích hợp kịch bản CLI (`packages/cli/src/verify-cli.ts`)  
**Target Platform**: macOS, Linux, Windows (Cross-platform path handling via `node:path`)  
**Project Type**: Multi-package monorepo (Skill layer + MCP Server + CLI package)  
**Performance Goals**:
- `npx qa-pilot init` hoàn thành khởi tạo trong < 2.0s
- Tra cứu payload qua `search-heuristics.js` trả về kết quả < 50ms  
**Constraints**: Zero-leakage token, secret redaction, plain functional Vietnamese copy, không dùng emoji trang trí.  
**Scale/Scope**: 1 Skill package, 1 CLI distribution package, tích hợp tương thích với Antigravity, Claude Code, Cursor.
