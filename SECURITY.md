# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of QA Pilot seriously. If you discover a vulnerability or security risk (e.g., unintended credential leakage, unsafe browser execution, or prompt injection vulnerability):

1. **Do NOT open a public GitHub Issue.**
2. Send an email to the maintainers at **hoangha1991@gmail.com** with details:
   - Type of vulnerability
   - Step-by-step reproduction instructions or proof-of-concept
   - Potential impact
3. We will acknowledge receipt of your report within 48 hours and work with you to patch the issue before public disclosure.
